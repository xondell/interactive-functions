Каждому x — ровно один y.

f: A → B, y = f(x)

x — аргумент; y — значение.

D(f) = A — допустимые x.
E(f) = f(A) — получаемые y.

Важно: E(f) ⊆ B. Не путай допустимые и получаемые значения.

Двигай вертикальную линию: для функции у каждого допустимого x только одно пересечение.
